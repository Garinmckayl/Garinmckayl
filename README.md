## Some of Projects

- **[Anima](https://github.com/Garinmckayl/anima)** ⭐31: Claude Code skill that turns a biology idea into an interactive, sourced, isometric figure (dopamine receptors, addiction circuits, semaglutide).
- **[thisvsthat](https://github.com/Garinmckayl/thisvsthat)** ⭐24: Learn web development by comparing different technologies side by side.
- **[Recall](https://github.com/Garinmckayl/recall)**: Persistent visual memory for home cameras. Ask "Where was Dad last seen?" and get one reconstructed answer with video evidence. Built on Amazon Nova and Ring, with an MCP server for Alexa+.
- **[Kinship](https://github.com/Garinmckayl/kinship)**: Voice-first AI care agent for older adults living alone. It tracks medications, follows up on its own, and guards against scams. Caregivers get a dashboard, and it works over phone and WhatsApp.
- **[Elora](https://github.com/Garinmckayl/elora)** ⭐1: Personal AI computer for your phone, powered by Gemini Live. Voice and vision, 40+ tools (Gmail, Calendar, browser, code sandbox), memory, and a self-extending skill system.
- **[Surge](https://github.com/Garinmckayl/surge)**: Founder-fit decision engine that ranks grants, accelerators and hackathons for a startup. It scores up to 10,000 opportunities and builds a 4-week application plan.
- **[Ombre](https://github.com/Garinmckayl/ombre)**: Managed security layer for OpenClaw. A two-way AI guardrail (97.8% accuracy on a 45-case adversarial test set) with isolated containers, secret injection and audit logs.
- **[AssistantX](https://github.com/Garinmckayl/assistantx)**: Secure AI assistant for journalists and activists under persecution. The agent never holds credentials (Auth0 Token Vault), with anomaly detection and a dead-man switch.
- **[Apollo](https://github.com/Garinmckayl/apollo)** ⭐1: Your autonomous AI SRE engineer.
- **[Arlo](https://github.com/Garinmckayl/arlo)**: AI companion for people with vision loss. It understands the whole page for your goal and remembers your preferences in Notion.
- **[Viri](https://github.com/Garinmckayl/viri)**: Chrome extension that protects against permanent crypto loss. It detects clipboard hijacking, lookalike addresses and suspicious patterns. [Live on the Chrome Web Store](https://chromewebstore.google.com/detail/viri-crypto-transaction-s/npmcebnngobklnbjgnglemfimmhgphbo).
- **[Salim](https://github.com/Garinmckayl/salim)**: Voice-first AI operating system for Dubai brokerages. It pulls DLD records, screens compliance, auto-fills RERA contracts and reconciles escrow, in four languages.
- **[LegalMindz](https://github.com/Garinmckayl/legalmindznova)**: AI legal platform for Ethiopia built on Amazon Nova. Contract drafting, risk analysis, Amharic voice consultation, and RAG over 65+ Ethiopian law articles.
- **[Nura](https://github.com/Garinmckayl/nura)**: AI network agent in a Go terminal UI. It monitors ping, DNS and HTTP, runs 9 diagnostics, and writes a report with GitHub Copilot CLI.
- **[AgntorShield](https://github.com/Garinmckayl/agntorshield)**: Onchain trust layer for AI agent economies on BNB Chain. [Live demo](https://garinmckayl.github.io/agntorshield).
- **[shelltutor](https://github.com/Garinmckayl/shelltutor)**: Interactive shell command tutor powered by GitHub Copilot CLI, with hands-on challenges and AI evaluation.
- **[devlog-cli](https://github.com/Garinmckayl/devlog-cli)**: AI developer journal that turns your git history into meaningful narratives, using GitHub Copilot CLI.
- **[Kesa](https://github.com/Garinmckayl/kesa)**: Investigative case management platform (Next.js and Supabase) for investigators and security teams. It has a 15-table schema with row-level security.
